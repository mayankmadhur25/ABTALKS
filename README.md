# ABTalks Redesign

A mobile-first redesign of the ABTalks 60 day build challenge.

Built with Next.js App Router, Tailwind CSS and mocked JSON data.
No authentication, no database, no real accounts, per the brief.

## Route Map

```text
/
/dashboard
/day/12
```

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 and set your browser width to 390px.
